你好呀，我是 fly，一个刚上大一的普通学生。

03 会的东西

分成六类，每类都还在慢慢练。

💻

技术

刚起步，正在认真学

  • Python从基础语法学到能写小项目，目前独立写出了猜数字这类程序
  • HTML / CSS / JS看得懂、改得动。这个页面就是跟 Agent 一起做出来的，我在旁边学
  • Git / GitHub会把代码传上去，正在习惯版本管理这套流程
🥁

音乐

打鼓的时候最专注

  • 架子鼓主要爱好之一，节奏感是练出来的，也是最能解压的事
  • 听歌练鼓顺手攒了一堆歌单，写代码的时候也离不开背景音乐
  • 游戏音乐打游戏时会特意去听配乐，有些 boss 战的曲子比歌单还耐听
🛹

运动

动起来才不困

  • 滑板还在练基本功的阶段，摔过几次但没放弃，滑顺一条线就很爽
  • 羽毛球约朋友打的那种，跑动多、出汗快，属于快乐运动
  • 夜跑晚上绕着操场跑几圈，跑完回宿舍洗澡睡觉，一天就算收尾了
🌶️

美食

无辣不欢

  • 吃辣口味偏重，微辣对我来说是起点。火锅、麻辣香锅、水煮系列都来者不拒
  • 找好吃的新到一个地方先看哪家店排队，学校周边基本被我摸过一遍了
  • 夜宵晚上十一点之后的一碗面，是当天最好吃的一顿（这个习惯不太好）
🎬

宅家

不出门也很快乐

  • 看番偏爱热血和日常两类，追更的时候一周里最期待的就是那天
  • 看电影周末窝在床上看一部，科幻和悬疑看得多一点
  • 刷视频说是休息，结果一刷一个小时。这个我承认是缺点
🌙

生活

一些没什么用但很开心的

  • 打游戏老本行，见上面「在玩的」那一栏
  • 折腾电脑喜欢把桌面整理整齐，然后过两天再弄乱
  • 熬夜不是好习惯，但夜里效率是真的高（正在努力改）
